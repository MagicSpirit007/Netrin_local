# Changelog

All notable public changes are documented here.

## 0.1.0 - 2026-08-23

- First open-source release of the local-first Netrin line.
- Added bundled PMTiles, campus paths, water data, and local webfonts for offline use.
- Added route recording, route selection persistence, network planning with direct fallback,
  and step-by-step navigation.
- Added optional Supabase route sharing with bounded client and SQL contracts.
- Added configurable root or `/netrin/` deployment, PWA smoke checks, tests, CI, and
  dependency automation.
